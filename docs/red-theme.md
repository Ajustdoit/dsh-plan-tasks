## 1. 现状：配色从哪来

「待执行」与「正在执行」用的是**同一支绿**，来自两条路径：

| 路径 | 位置 | 形态 |
| --- | --- | --- |
| **A. 组强调色** | `02-content.css:170` `.plt-group-todo{--plt-accent:34,197,94}` | CSS 变量（RGB 三元组） |
| **B. 硬编码** | 41 处散在 `02-content.css` / `03-theme.css` | 直接写 `rgba(34,197,94,…)` / `rgba(22,101,52,…)` |

浅色覆盖一处：`03-theme.css:84` `body:not(...) .plt-group-todo{--plt-accent:22,101,52}`。

**关键事实：组色不是唯一来源。** 只改 `--plt-accent` 会出现「组头变红、里面跑着的那条还是绿」——
因为「执行中」的边框、内阴影、扫光渐变、状态徽标全是硬编码，不跟变量走。
（这正是 id=406 把待执行改绿时踩过的同一个坑：当时 16 处，现在 **45 处**。）

### 状态是如何判定的（类名来源）

`src/client/30-runtime.js` 的 `statusOf()` 返回 `{ key, label }`：

| key | label | 用在哪 |
| --- | --- | --- |
| `todo` | 待执行 | `.plt-group-todo`（组）、`.plt-tag.todo`（已随状态标记移除而废弃） |
| `running` | 执行中 | `.plt-item.running`、`.plt-tag.running`、`.plt-kid.running` |

类名是**拼出来**的：`plt-group-${group.key}`、`plt-tag ${status.key}`，
所以 CSS 里看到的 `plt-group-todo` / `running` 这两个字符串都要与实际 key 一致。

### 对比度实测（WCAG 公式，非估算）

| 主题 | 颜色 | 底色 | 比值 | 门槛 |
| --- | --- | --- | --- | --- |
| 深色 | `#f05252` | `rgb(22,24,28)` | **5.11 : 1** | ≥4.5 ✓ |
| 深色 | `#ff5c5c`（执行中） | 同上 | **5.87 : 1** | ≥4.5 ✓ |
| 浅色 | `#b91c1c` | `#fff` | **6.47 : 1** | ≥4.5 ✓ |
| 浅色 | `#991b1b`（执行中） | `#fff` | **8.31 : 1** | ≥4.5 ✓ |
| 深色 | `--plt-todo-fg` | 浅红底 α=.16 | **10.48 : 1** | ≥3.0 ✓ |
| 浅色 | `--plt-todo-fg` | 浅红底 α=.16 | **6.33 : 1** | ≥3.0 ✓ |

### 为什么必须深/浅两套

题面点名「避免纯深红配深色底」—— 实测正是如此：

| 颜色 | 在深底 `rgb(22,24,28)` 上 |
| --- | --- |
| `#8b0000`（纯深红） | **1.78 : 1** ✗ 完全糊掉 |
| `#7f1d1d` | **1.77 : 1** ✗ |
| `#991b1b` | **2.14 : 1** ✗ |

同一支红在两套底色上不可能都达标：深底需要**亮**（≥4.5 要 #ef4444 以上），
白底需要**深**（#f87171 只有 3.34:1，不合格）。所以分两套，不是冗余。

### 待执行 vs 执行中：需要层级差

| 主题 | 待执行 | 执行中 | 差异 |
| --- | --- | --- | --- |
| 深色 | `240,82,82` | `255,92,92` | 更亮（RGB 距离 21） |
| 浅色 | `185,28,28` | `153,27,27` | 更深（白底上「更醒目」=更深） |

两者只差一档，靠**描边加粗/实心填充**进一步区分（78-C 做）。

### 替换时务必注意

1. **别只改 `--plt-accent`** —— 45 处硬编码不跟它走（见第 1 节）；
2. **`plt-group-${key}` 是拼出来的** —— 改 key 或在 CSS 里改类名要两边对齐；
3. **浅色的 13 条覆盖规则**要一起换，否则浅色主题会残留绿色；
4. **`color-mix` 那处**（`.plt-group-run` 提亮 55%）要确认换成红后仍够亮；
5. `--plt-run-glow` 是扫光渐变里的高光，浅色下用白色而不是浅红。
